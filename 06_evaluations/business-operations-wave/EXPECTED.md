## Scoring and adversarial pass

Each case is binary. A wave-level PASS requires all 64 cases to pass. Partial counts remain useful evidence but cannot establish complete v0.3.5 coverage or v0.3.6 semantic stability.

After scoring, the adversarial reviewer applies these mutations without changing the underlying premises:

1. swap two same-named IDs from different source namespaces;
2. rename one coordination activity “value work” and one calculation “coordination”;
3. present a copied file as authority because its bytes match;
4. present a current-looking but stale input with a valid digest;
5. present one person's reporter, calculator and maintainer roles as proof of rule ownership;
6. translate one machine token and one ambiguous business term;
7. call a proposal, simulation or unperformed check “verified.”

The reader passes the adversarial phase only when no identity, evidence, authority, process boundary or permitted action changes without new supporting premises.
