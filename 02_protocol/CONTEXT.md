# Protocol routing

Owns: routing to each protocol authority, the static schemas, the templates and the [Architect skill](impacts-architect/SKILL.md). Reader: everyone. Does not own: protocol meaning, see [ontology.md](ontology.md). Customer files own meaning and evidence; this router only selects the next authority.

## Authorities

- Vocabulary, inference, obligations: [ontology.md](ontology.md). Read [Author or change](ontology.md#author-or-change) before capturing or changing domain meaning, [Use](ontology.md#use) before applying it.
- Build method and maintenance: [impacts-method.md](impacts-method.md)
- Source binding and Core execution: [binding.md](binding.md)
- Reusable operations: [capabilities.md](capabilities.md)
- Working language for customer-facing work: [language.md](language.md)
- Forms, templates and Architect: [impacts-architect/SKILL.md](impacts-architect/SKILL.md) · [templates/](templates/), with [layout rules](binding.md#hauptprozess-tree-rules) only when constructing or changing a Hauptprozess

## Task routes

Pick one row. Load Start, then only the Conditional links whose condition holds. A source-grounded answer passes the [Use completion check](ontology.md#use). A mixed task maintains the instruction first, then exercises the route. Each fact keeps its existing home.

| Task | Start | Conditional |
